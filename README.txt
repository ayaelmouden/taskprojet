TASKFLOW — Aya Elmouden

Application de gestion des tâches réalisée en HTML, CSS et JavaScript.

Lancement :
1. Décompresser TaskFlow_Project.zip.
2. Ouvrir le dossier TaskFlow dans Visual Studio Code.
3. Lancer index.html avec Live Server (ou ouvrir directement le fichier dans le navigateur).

Fonctionnalités :
- Ajouter, modifier et supprimer des tâches
- Marquer une tâche comme terminée ou en attente
- Choisir une date limite et un niveau de priorité
- Filtrer les tâches par statut
- Rechercher une tâche
- Consulter les statistiques
- Basculer entre le thème clair et sombre
- Sauvegarde automatique dans le LocalStorage

Technologies : HTML5, CSS3, JavaScript, LocalStorage.
Les données restent enregistrées dans le navigateur utilisé.
